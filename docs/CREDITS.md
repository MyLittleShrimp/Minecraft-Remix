# 鸣谢与素材说明

- **项目**：Minecraft Remix；中文副标题为“方块远征”。
- **引擎**：Godot 4.7.2；[引擎许可证](../assets/legal/godot_LICENSE.txt)与[版权名单](../assets/legal/godot_COPYRIGHT.txt)随游戏提供。
- **字体**：Fusion Pixel Font；附带 [Fusion Pixel](../assets/legal/FusionPixel-OFL.txt)、[Ark Pixel](../assets/legal/ArkPixel-OFL.txt)、[Cubic 11](../assets/legal/Cubic11-OFL.txt)、[Galmuri](../assets/legal/Galmuri-LICENSE.txt) 许可原文。
- **美术**：部分角色、背景、道具、标题与图标经 ImageGen 辅助生成，随后整理图集并接入；也包含程序绘制元素。
- **战斗特效**：采用本地像素特效生成与程序绘制，图集随源码提供；没有改变角色原有攻击判定。
- **音乐**：项目作者提供十六首 MP3。对应清单：[探索与主题音乐](../assets/audio/music/source_manifest.json)、[Boss 音乐](../assets/audio/music/boss_source_manifest.json)。
- **宣传素材**：游戏内录制画面剪辑而成，见 [预告片说明](TRAILER.md)。
