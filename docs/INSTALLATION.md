# 下载、安装与操作

## Windows 免安装版

当前版本：**v0.2.0.66 / Windows x64**。

1. 在本仓库 [Releases 下载页面](https://github.com/MyLittleShrimp/Minecraft-Remix/releases/tag/v0.2.0.66)下载 `MinecraftRemix-v0.2.0.66-Windows-x64.zip`。自动提供的 **Source code (zip)** 是源码，不是可直接运行的游戏。
2. 右键 ZIP 选择“全部解压”。不要在压缩包预览窗口中直接启动。
3. 在解压目录双击 `MinecraftRemix.exe`。

EXE 与 `MinecraftRemix.pck` 必须同目录；请保留 README、图标和 legal 文件夹。无需安装 Godot、Python、Java 或 Minecraft。

当前提供便携版；历史 0.2.0.63 安装器不包含本版 Boss 音乐和后续修复，不作为本次推荐下载。

## 操作与设置

| 功能 | 默认键 |
| --- | --- |
| 移动 / 跳跃 | A、D / 空格 |
| 向下穿过单向平台 | S + 空格 |
| 攻击或蓄力 / 切换武器 | J / K |
| 大招 / 交互、武器架 | L / E |
| 斜上瞄准 | W + 远程攻击 |
| 暂停 / 设置 / 全屏 | Esc / F1 / F11 |

在 F1 设置中切换键盘或手柄，调整向导、音乐音量和手柄死区。手柄映射可自行录入；占用的按键交换映射。不同品牌设备的识别情况需要实机确认。

右下角音符按钮单独控制背景音乐，音效不受影响。Boss 战自动切换专曲，二阶段连续播放。

## 存档与更新

- 路标自动保存；离开时未结算的一段进度回滚。失败默认选择“重试路标”，回车执行当前高亮选项。
- 单关游玩与主线远征分开；从指定章节开始新远征请阅读游戏内确认提示。
- 存档和设置位于 `%APPDATA%\Godot\app_userdata\Minecraft Remix\`，不在游戏解压目录。
- 更新时将新版解压到新文件夹再启动，原有用户存档仍可读取。需要备份时复制整个用户目录。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 找不到游戏数据、无法启动 | 是否完整解压，EXE 与 PCK 是否同目录，文件是否下载完整 |
| 没有背景音乐 | 音符按钮、F1 音量、Windows 音量混合器是否静音 |
| 手柄没有反应 | 是否选中设备并保存映射；连接后重新打开设备列表 |
| 画面没有全屏 | 按 F11；最大化窗口和游戏全屏是两种模式 |
| 黑屏或闪退 | 提供显卡、Windows/游戏版本、复现步骤，附用户目录 logs 中最近日志 |

另一物理设备的完整兼容性验收与最低配置尚未完成。反馈时请注明具体版本。

Release 附带 `SHA256SUMS.txt`，可用 PowerShell 命令 `Get-FileHash .\MinecraftRemix-v0.2.0.66-Windows-x64.zip -Algorithm SHA256` 与表中同名文件核对。
