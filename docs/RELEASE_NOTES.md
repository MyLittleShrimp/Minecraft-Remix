# Minecraft Remix v0.2.0.73 · 战斗特效更新

Windows x64 单人测试版。本次整合 v0.2.0.67–0.2.0.73 的本地更新，上一公开版本为 v0.2.0.66。

## 更新内容

- **剑光与雷霆**：普通挥砍接入像素弧光；巨剑弧线加大加厚。三叉戟三目标天空落雷增加分叉核心、地面电环与青蓝辉光。
- **敌人攻击**：女巫伤害药水与毒药水使用不同色彩的爆裂、毒雾和附着气泡；药水反馈略放大并延长。末影人传送显示旋涡落点，精英真身与残影可辨。
- **凋灵**：聚能、狂暴冲刺、撞柱与头颅弹命中加入能量爆散，两阶段颜色不同。
- **爆破与反弹**：TNT 火团、贴地冲击波、碎石和烟尘；苦力帕白烟与绿色碎屑；恶魂火球以青色尾焰显示成功反弹。TNT 视觉范围在打磨后收紧。
- **收集与补给**：绿宝石、食物、增益分色反馈；回血显示光环、十字与实际恢复量。
- **终章表现**：最终 Boss 攻击与阶段转换的视觉表现升级，公开视频不展示最终战。

上述特效沿用已有命中窗口、伤害和危险范围；没有用新增光效扩大攻击判定。七关、五武器、十六首音乐、音乐开关、输入映射及失败菜单修复继续保留。

## 下载哪个文件

- **MinecraftRemix-v0.2.0.73-Windows-x64.zip**：完整免安装游戏，全部解压后运行 MinecraftRemix.exe。
- **MinecraftRemix-Update-v0.2.0.73-80s-1080p.mp4**：80 秒横屏更新介绍，当前版本实机重新录制。
- **MinecraftRemix-Update-Cover.jpg**：视频封面。
- **INSTALLATION.zh-CN.txt**：操作、安装与更新说明。
- **SHA256SUMS.txt**：以上附件的 SHA256 校验值。

Source code 压缩包供开发者使用，不是可直接运行的游戏。旧版本发布页继续保留；旧 0.63 安装器不含本次更新。

## 更新与反馈

新版解压到新目录启动即可，沿用原用户存档目录。建议先备份 `%APPDATA%\Godot\app_userdata\Minecraft Remix\`。本次没有改动存档格式。

最新游戏包的源码与 PCK 各通过 205 项末影龙特效、龙息躲避、高塔及发布冒烟检查；便携包内部文件哈希和 ZIP 完整性已核对。前几批特效也分别完成专项验收。本次发布另核对干净源码导入、冒烟及导出链路。

未完成其他物理设备、低配机器和实体手柄的全面验收，也未重新人工打通七关。双人合作和武器升级系统尚未实现。
