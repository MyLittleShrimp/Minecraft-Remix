# 游戏介绍

《Minecraft Remix》（中文副标题：方块远征）是一款 Minecraft 主题的非官方单人横版动作冒险：穿越七个区域，用五种武器应对不同敌人，把平台跳跃、道具收集和机关解谜串成一段完整旅程。

## 这场远征

扮演 Steve，从绿意中的林地遗迹出发，穿过蛛影林径、废弃矿道、潮汐遗迹和诡异边界，再深入堡垒与更远的未知之地。熟悉的怪物换了一种战斗方式：骷髅从高处放箭，蜘蛛跃入近身距离，女巫投掷药水，恶魂从空中施压。

每关都有不同环境、补给路线和关底挑战。新手可打开向导阅读沿途提示；熟手可关闭教学信息，保留操作底栏与危险预警。

## 五把武器，两种选择

| 武器 | 手感与用途 |
| --- | --- |
| 下界合金剑 | 近身连续挥砍，跳劈增加伤害 |
| 弓 | 蓄力控制伤害，利用距离与斜上瞄准 |
| 弩 | 一次装填两发，在装填和连续射击之间安排进攻 |
| 重斧 | 更长的近战范围与重击，抓住敌人收招破绽追击 |
| 三叉戟 | 投掷后回收，兼顾近远距离，大招召来三道索敌落雷 |

武器随关卡开放，在武器架选择两槽配装。收集 20 颗绿宝石可释放一次当前武器的大招；绿宝石跨关保留，何时使用由你决定。

## 支线值得跳一下

悬空的绿宝石需要跳跃才能取得，高处箱子可能藏着补给。问号砖中的蘑菇提供力量、治疗、迅捷或守护效果；裂纹藏宝箱保留随机掉落。跳跃与战斗消耗饱食度，食物和小动物掉落帮助继续探索。

机关包含 TNT 搬运、爆破开路与灵魂导流，既要看准路线，也要应对沿途袭扰。部分战斗需要观察预警、利用地形或把投射物反击回去。

## 声音与画面

像素角色与分层场景搭配统一像素 UI。0.73 更新了剑光、落雷辉光、敌人攻击、爆炸、反弹和拾取反馈。菜单、七关探索、七场 Boss 战与胜利共十六首音乐，随游戏状态切换；音乐音量与开关独立于战斗音效。

当前为 Windows 单人测试版，支持键盘与可映射手柄。双人合作与武器升级系统属于后续规划。
